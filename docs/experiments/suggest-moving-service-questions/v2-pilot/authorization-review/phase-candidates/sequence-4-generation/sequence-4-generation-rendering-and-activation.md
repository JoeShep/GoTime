# Sequence-4 generation rendering and activation

This package is an offline, inactive generation-only candidate bound to the
approved sequence-4 preflight evidence. It grants no authority. Operational
commands are documented only in the sequence-4 generation operator runbook.

Generation must use the exact preflighted deterministic request and may perform
zero token preflights, one generation, and zero retries. Any mismatch fails
before credential inspection. Activation, a provider request, and generation
remain separately unauthorized until later human milestones.
